# MOL Digital Twin V2.1

Interaktywna demonstracyjna mapa 3D magazynu ESTYL. HTML + Three.js z CDN. Publikacja przez GitHub Pages.

## Użytkowanie
Otwórz index.html przez GitHub Pages. Obracaj, przybliżaj, wybieraj regały, wyszukuj lokalizacje, odtwarzaj trasę. Trasa demo jest wyznaczana przez A* po poglądowej siatce przejść i może wymagać poprawy wobec rzeczywistych alejek.

## Granice modelu
Rozmieszczenie i wysokości są schematyczne. Oznaczenia pochodzą z planu 'PLAN MAGAYNU LOKALIZACJE.pdf', lecz nie jest to dokładna inwentaryzacja techniczna. Brak integracji produkcyjnych i danych o pracy rzeczywistej. Model jest publiczny — nie należy dodawać danych klientów, tokenów ani informacji operacyjnych.

## Deployment
GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save. Docelowy URL: https://atybus-create.github.io/mol-warehouse-3d/
